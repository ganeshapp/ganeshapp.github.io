# Repository workflow

- Pull the latest remote changes before committing and again before pushing. This
  repository also receives posts from Jekyllpress on mobile. Preserve those posts
  and any other remote changes when integrating local work; never force-push over
  them.
- Do not add AI attribution, co-author trailers, or generated-by notices to
  commits, pull requests, issues, release notes, or published content. Commits
  must use the owner's author identity.
